# Shared support libraries: current behavior

This page records the behavior visible in the checked-in source for reusable Swing components, shared utilities, and ZIP operations. It is a static source analysis; no build, application launch, or runtime test was performed. Links are relative to this document and point to implementation evidence.

## Swing component package

The `com.myjavaworld.gui` package wraps Swing components used by the application and the TLS dialogs. Most wrappers preserve their Swing superclass behavior while adding localized mnemonic setters, layout defaults, custom renderers, busy overlays, or text-document behavior. Cross-package callers include dialogs in `jftp/ssl`, so changes to the shared interfaces can alter certificate/security workflows as well as ordinary screens.

### Text input and editing

[`MTextComponent`](../src/main/java/com/myjavaworld/gui/MTextComponent.java#L23) defines the common text-editing contract and case constants. [`MPlainDocument`](../src/main/java/com/myjavaworld/gui/MPlainDocument.java#L29) truncates insertions at its configured maximum length, beeps when truncating, and uppercases or lowercases the inserted string according to `MTextComponent` constants. A non-positive or negative maximum is not validated; a negative substring bound can fail. Case conversion uses the JVM default locale. [`SingleLineDocument`](../src/main/java/com/myjavaworld/gui/SingleLineDocument.java#L26) truncates each insertion at the first CR or LF before delegating to `MPlainDocument`, so pasted multiline strings contribute only their prefix.

[`MTextField`](../src/main/java/com/myjavaworld/gui/MTextField.java#L35) and [`MLabelTextField`](../src/main/java/com/myjavaworld/gui/MLabelTextField.java#L35) install `SingleLineDocument`; [`MTextArea`](../src/main/java/com/myjavaworld/gui/MTextArea.java#L33) installs `MPlainDocument`. The field classes select all on non-temporary focus gain and clear the selection on non-temporary focus loss. `MTextField` and `MTextArea` attach an `UndoManager` with an initial limit of one edit. `MLabelTextField` is intentionally non-editable, transparent, borderless, and also starts with a one-edit undo limit; its `setText` lazily attaches the undo listener. `MTextField.setText` and `MLabelTextField.setText` reset the caret to position zero. Replacing a document attaches the undo listener before forwarding to Swing.

`MPasswordField` uses `SingleLineDocument`, selects all on focus gain, clears selection on focus loss, and exposes a no-op undo/redo implementation. Copy and cut are always disallowed, while paste is allowed when editable and the system clipboard exposes string flavor. `MTextField`, `MTextArea`, and `MLabelTextField` query the system clipboard in `canPaste`; a headless environment, clipboard security error, or null clipboard transferable can fail at that call. Their popup actions are enabled from these `can*` results by the shared singleton [`EditPopupMenu`](../src/main/java/com/myjavaworld/gui/EditPopupMenu.java#L31), which targets whichever `MTextComponent` most recently invoked it. The popup handles platform popup triggers on both mouse press and release and throws `IllegalArgumentException` when shown for another component type. The password field's menu contract deliberately suppresses cut/copy/undo/redo; changing that policy exposes secrets and needs a deliberate security decision.

Other input wrappers mainly forward Swing constructors: `IntegerField` uses an inner `SingleLineDocument` that accepts insertions only when the resulting text parses as an integer, with the intermediate single character `-` allowed; rejected edits beep. Empty text remains possible and `getValue()` then throws `NumberFormatException`. The integer document parses the entire candidate string, so a sign-only string is accepted only as exactly `-`. `MComboBox.setData` clears existing items then appends array/vector values. `MList` and `MTree` add constructors without additional behavior. `MCheckBox`, `MRadioButton`, `MRadioButtonMenuItem`, `MMenu`, `MMenuItem`, `MButton`, and `MLabel` add string-based mnemonic helpers; combined mnemonic setters skip mnemonic assignment on macOS, but assume non-null mnemonic and index strings there as well as elsewhere.

### Dialogs, progress, and worker threading

[`MDialog`](../src/main/java/com/myjavaworld/gui/MDialog.java#L35) makes dialogs non-resizable by default, uses `DO_NOTHING_ON_CLOSE`, and hides rather than disposes on Escape or window close. Subclasses can override `escape()`. The window-close path also hides the dialog. `LicenseAgreementDlg` is modal, loads a URL into a non-editable HTML `JEditorPane`, and sets `licenseAgreed` only when Agree is activated; Escape clicks Disagree. A page load failure prints a stack trace and replaces the page with a support message. [`ProgressDialog`](../src/main/java/com/myjavaworld/gui/ProgressDialog.java#L35) is indeterminate initially; its Cancel button is initially disabled, and callers attach action listeners and explicitly enable it. It exposes progress/message setters and repacks before showing. Hiding the dialog is not cancellation by itself.

[`SwingWorker`](../src/main/java/com/myjavaworld/gui/SwingWorker.java#L30) is an application-owned pre-JDK SwingWorker API, not `javax.swing.SwingWorker`. Its constructor creates one thread; callers must call `start()`. `construct()` runs on that worker, its return value is published under synchronization, and `finished()` is posted with `SwingUtilities.invokeLater` to the event dispatch thread only after normal completion. A thrown exception escapes the worker thread but the `finally` still clears the worker reference; in that case `finished()` is not posted. `get()` joins and can block the caller; if the caller is interrupted it restores interrupt status and returns null. `interrupt()` interrupts and clears the thread reference, so a later `get()` may return the current value before the worker actually exits. These lifecycle details must be characterized before substituting the JDK worker API.

[`MFrame`](../src/main/java/com/myjavaworld/gui/MFrame.java#L29) installs a content panel with caller-supplied insets and a busy glass pane. `setBusy` changes the cursor and makes the glass pane visible; the pane consumes mouse/key events. `MInternalFrame` uses the same overlay but raises/selects itself on a busy-overlay mouse press and writes caught selection exceptions to stderr. `MDesktopPane.cascade`, `tileHorizontally`, and `tileVertically` rearrange only open non-iconified frames; the algorithm preserves the selected window by not explicitly changing selection. `SplashWindow.setVisible(true)` centers the window; it does not sleep despite its method comment.

### Renderers, themes, and convenience helpers

`MTable` installs `MTableHeaderRenderer` and computes row height from font metrics. For popup triggers it preserves an existing selected row when clicked, otherwise selects the clicked row, and clears selection when clicked outside rows. `MDefaultRenderer`, `ImageCellRenderer`, and `MTableCellRenderer` display `null` as the literal string `null`; `NumericCellRenderer` and `DateCellRenderer` use the default locale's number/date formatters. The table branch in both `MDefaultRenderer` and `ImageCellRenderer` currently sets selected foreground from `getSelectionForeground()` for both foreground and background. `ImageCellRenderer` also implements tree rendering using colors captured from `UIManager` at class initialization. `MTableHeaderRenderer` captures UI defaults at construction and retains its configured icon when rendering a header whose current icon is null.

Theme classes provide Default, Green Metal, High Contrast, Sandstone, and corresponding large-font variants. They extend `DefaultMetalTheme` through `DefaultTheme`; large variants use bold 16-point dialog fonts and 12-point subtext fonts. Theme names and color/font values are observable UI behavior. [`GUIUtil`](../src/main/java/com/myjavaworld/gui/GUIUtil.java#L39) derives shortcut masks from `Toolkit`, help/delete keys from the platform, centers components against the primary screen bounds, and provides JOptionPane wrappers. `showError(Component, Throwable)` displays a formatted throwable and prints its stack trace. `htmlFormat` converts newlines/tabs and inserts input directly into an HTML table; it does not escape markup.

## Utility package

[`ResourceLoader`](../src/main/java/com/myjavaworld/util/ResourceLoader.java#L31) loads `ResourceBundle`s for the default or explicit locale/class loader. On `MissingResourceException` it prints a stack trace, reports to stderr, calls `System.exit(1)`, then nominally returns null. Callers such as `CommonResources` initialize bundles statically, so missing bundles can terminate application startup. Resource selection and fatal-failure behavior are part of the startup contract.

[`Encoder.hexEncode`](../src/main/java/com/myjavaworld/util/Encoder.java#L24) produces two uppercase hexadecimal characters per byte. [`RandomKeyGenerator.generate`](../src/main/java/com/myjavaworld/util/RandomKeyGenerator.java#L38) uses `SecureRandom`, rejects lengths below one, and actually generates only uppercase A–Z (despite its comment claiming digits too). `formatKey` inserts hyphens before each character whose zero-based index is divisible by four; it does not validate key shape. [`StringUtilities.getFormattedMessage`](../src/main/java/com/myjavaworld/util/StringUtilities.java#L27) defaults to 120 characters, uses space-delimited tokens for long lines, and can normalize/collapse whitespace on those lines; short lines are appended unchanged. Do not treat this as a lossless text formatter.

[`FileUtilities.copyFile`](../src/main/java/com/myjavaworld/util/FileUtilities.java#L30) copies bytes through 4 KiB buffered streams and opens the target with `FileOutputStream`, overwriting it. It does not create parent directories, preserve metadata, or stage atomically. `SystemUtil` snapshots OS/JRE/user-home/working-directory properties once during class initialization; unavailable properties become `Unknown`, and its macOS check looks for `Mac OS X` in `os.name`.

`FileChangeMonitor` stores `File` keys and initial `lastModified()` values in a `Hashtable`. Adding the first file starts a one-second Swing `Timer`; timer callbacks therefore run on the Swing event dispatch thread. It reports only when the observed timestamp strictly increases. It does not report deletion, creation with unchanged/older time, content changes with preserved timestamp, or timestamp decrease. `remove` does not stop the timer when the set becomes empty; `stopMonitor` stops the timer but leaves registrations in place; because it retains the non-null stopped timer, later `add` calls do not restart monitoring. Listener callbacks run synchronously in reverse listener-registration order on the timer's EDT. A slow listener blocks the UI. `FileChangeEvent` exposes mutable public fields and getters, including the existing lowercase-n getter `getnewDate()`.

`ProgressEvent` and `StatusEvent` are simple immutable-by-interface `EventObject` payloads, with `ProgressListener` and `StatusListener` callback interfaces. The ZIP code uses the same progress event type.

## ZIP operations

[`Zip`](../src/main/java/com/myjavaworld/zip/Zip.java#L35) writes a target using `ZipOutputStream`; call `open()` before `addEntry()` and `close()` when done. `open()` truncates an existing target. Adding the target to itself is skipped only for `File.equals`. Each entry carries the source file's last-modified time. Directories are written with a trailing slash and recursively enumerated through `LocalFile.list(filter)`; child ordering/filter semantics therefore come from that class. File data is streamed in 16 KiB chunks. Progress is an integer percentage of each individual file, not the full archive. Empty files emit begin/end callbacks but no progress callback. Listener exceptions propagate inline and can abort the operation; callbacks run synchronously on the calling thread.

`setRelativeTo` stores a canonical path, falling back to absolute path on canonicalization error. `computeEntryName` takes a raw substring beginning at `relativeTo.length()` without checking that the file is below the root or on a path-component boundary. Files outside that root can produce malformed names or `StringIndexOutOfBoundsException`; a sibling sharing the same character prefix can be misclassified. ZIP entry names replace the platform separator with `/`. This is a current path-construction defect; archive root semantics must be decided and covered before correction.

[`Unzip`](../src/main/java/com/myjavaworld/zip/Unzip.java#L35) defaults extraction to the archive's parent directory, requires `open()` before `unzip()`, and requires a separate `close()`. Directory entries are created only if absent and receive their stored timestamp only on creation. File entries create missing parent directories and overwrite existing target files. File bytes are streamed in 16 KiB chunks; progress is an integer percentage within each file, derived from entry size. Begin/end events use the target basename, but the end callback is passed the archive `file` field rather than the extracted target. The `finally` fires end before stream close, including when opening/writing fails. `close()` closes the ZipFile but does not set the field to null, so reopening or closing again can fail.

**Security defect:** extraction joins the untrusted entry name directly to `targetDirectory` and does not canonicalize or verify containment. Entries containing parent traversal or absolute-path forms can write outside the selected destination, subject to platform path semantics and permissions. This is not a behavior to preserve. Add traversal regression coverage in an isolated temporary directory before implementation changes; safe extraction should reject/contain such entries while keeping ordinary nested-file extraction and overwrite semantics explicit.

### Compatibility notes

Static inspection found legacy APIs but no references to `sun.*` or `com.sun.*` implementation packages in the owned Java source. `GUIUtil` uses the deprecated `Toolkit.getMenuShortcutKeyMask()` API; certificate presentation/trust uses deprecated `X509Certificate.getSubjectDN()` / `getIssuerDN()`; `FileChangeMonitor` constructs boxed `Long` values explicitly. These are modernization hotspots and possible future JDK compatibility issues, not proof of a current compile failure. The custom `com.myjavaworld.gui.SwingWorker` is a public source-compatibility boundary and must not be confused with the JDK class of the same simple name.

## Regression candidates for the coordinator

These are proposed observable cases only; no tests were added or executed here.

1. **Archive round-trip plus traversal rejection.** In a fresh temporary tree, create a directory containing a nested file, a zero-byte file, and a timestamped file; ZIP relative to the root, extract into a second empty directory, and compare entry names, bytes, timestamps and emitted begin/end/progress events. Add a crafted `../outside.txt` entry and assert no file appears outside the extraction root and the operation reports/rejects the unsafe entry. Keep all paths under one temp root. The traversal assertion is an intentional security correction and is expected to fail against the current baseline; the coordinator should gate it as a defect-fix case rather than report it as a passing legacy contract.
2. **FTPS trust decisions with isolated stores.** Use a controlled local FTPS endpoint, a fresh temporary `user.home`, and generated test certificates. Assert a trusted host-matching certificate connects without a prompt; an unknown matching certificate prompts and acceptance permits the current connection but does not persist trust; rejection fails the connection. Add expired and hostname-mismatch cases and assert the current dialog's displayed flags and accept/reject results. These cases preserve observable prompts while making the current acceptance policy explicit; any stricter policy requires a separate decision.
3. **Preference/favorite compatibility fixture.** In a temporary user home, seed the serialized preference and favorite formats, including configured JKS paths, passwords, and a favorite with a password; load, save, restart, and confirm the existing values and files remain readable. Include legacy plaintext favorite-list migration and the AES-wrapped form. Do not use live user profile files or credentials.
4. **Text editing contract.** On the Swing EDT, insert mixed-case, over-limit, and multiline text into MTextField, MTextArea and MPasswordField; assert resulting text, beep-independent truncation, selection/focus behavior, clipboard action enablement where a controlled clipboard is available, and the password cut/copy/undo suppression. Use a private clipboard or skip clipboard-specific assertions only when the fixture cannot provide one; do not weaken core document output checks.
