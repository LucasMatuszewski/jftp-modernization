## Coverage boundaries

Root scans have no subtree restriction. Only generated `docs/repo-maps/*` and local `.codex/*` state are explicitly excluded. The native policy also excludes symlinks, binary files, oversized files and non-UTF-8 content. The complete run records 109 binary skips, 41 non-UTF-8 skips, one symlink skip, and one size-limit skip (`assets/homepage.png`). Their tracked paths remain in the structure inventory; symbol-map omission does not establish absence from JFTP.

XML/properties/JSON and other readable text are inventoried, not parsed as declarations. A complete captured-definition index is a navigation aid, not a resolved call graph or runtime verification. Refresh after path/declaration changes.

## Reproduction

The pinned release installer reported that release `legacy-tools-v0.2.0` was unavailable. The existing Windows x86-64 CI package was independently revalidated with the installed setup script; status was `ready`, version `0.2.0`, clean build source `d0181792fba3026c20f5b4fbc1595f7d38abc688`. Its prior authenticated provenance is documented in [the final CI consumer evidence](artifacts/2026-10-08/windows-final/final-results.json). Exact generation arguments, verified package status and measured subprocess times are in [generation evidence](artifacts/jftp.structure/generation.json).

Run the verified `program` from `setup_native.py status` on the repository root with external staging, `--exclude docs/repo-maps/* --exclude .codex/* --budget 16384`; use a separate staging directory with `--all-definitions --budget 65536` for the index. Export with `scripts/export_repo_map.py --implementation rust` and the respective `jftp.rust.md` / `jftp.full.rust.md` output paths. Keep generated bytes unchanged so raw/report hashes remain valid.
