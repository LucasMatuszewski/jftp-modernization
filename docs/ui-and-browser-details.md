# UI, file browsers, connection settings, and dialog contracts

This document describes the current source behavior of the assigned 44 top-level UI classes under `com.myjavaworld.jftp`. It complements [application workflows](application-workflows.md) with browser and dialog detail. Source links point to the implementation; no UI was launched and no tests or builds were run during this review.

## Browser rows, selection, and navigation

[LocalPane](../src/main/java/com/myjavaworld/jftp/LocalPane.java) and [RemotePane](../src/main/java/com/myjavaworld/jftp/RemotePane.java) render four local columns (name, type, size, modified) and five remote columns (the same plus attributes) through [LocalFileTableModel](../src/main/java/com/myjavaworld/jftp/LocalFileTableModel.java) and [RemoteFileTableModel](../src/main/java/com/myjavaworld/jftp/RemoteFileTableModel.java). Column labels are resolved from corresponding `LocalFileTableModel.properties` and `RemoteFileTableModel.properties` bundles. The name cell receives the full file object; other cells display type, numeric size, date, and on the remote side attributes. Both tables disable automatic column resizing, use single model arrays as data, and install custom date/numeric/icon renderers.

Local rows wrap [LocalFile](../src/main/java/com/myjavaworld/jftp/LocalFile.java), which delegates roots, display names, icons, type descriptions, traversal checks, parent lookup, and child listing to Swing `FileSystemView`. It snapshots filename, size, modified time, and directory status in the constructor, while methods such as `exists`, `canRead`, `canWrite`, `isHidden`, and `delete` query the underlying `File`. Local listing calls `FileSystemView.getFiles(directory, false)`, so hidden-file visibility is filtered by `LocalFileFilter`, not by asking FileSystemView to hide hidden children. Roots are selectable separately; the working-directory combo is rebuilt as a root-to-current breadcrumb using canonical parents where available. A path that is not canonicalizable falls back to the input `File` object.

Remote rows are `com.myjavaworld.ftp.RemoteFile` records from the FTP API. RemotePane's directory combo tracks visited/current directories by equality; Up delegates to the session; refresh re-sets the current remote directory. A double click on a directory or link navigates into it; a file double click invokes the open-file action. Local double-click invokes the local open action for the current table selection. Both panes register Enter to open and Delete to delete. Both use drag-and-drop through `DnDTransferHandler`.

Both panes sort the underlying data array when a header is clicked, and toggling the same sortable column changes ascending/descending. Name, type, size, and modified-date sorts are implemented in [LocalFileComparator](../src/main/java/com/myjavaworld/jftp/LocalFileComparator.java) and [RemoteFileComparator](../src/main/java/com/myjavaworld/jftp/RemoteFileComparator.java). Directories sort ahead of files in ascending order, but descending reverses that rule too. Name comparisons uppercase strings using the default locale; local name sorting uses display names except for filesystem roots. Type sorting uses platform display type locally and API type remotely. Size sorting uses numeric size, with name tie-breaks; date sort has no secondary tie-break. The remote table's attributes column is not sortable. There is no `RowSorter` in these pane classes, so selected view row indices currently correspond to model array indices. Keep that mapping explicit if introducing a sorter.

Selection is multi-row. `getSelectedFile(s)` reads the table's selected row(s); selected status counts and sums each selected row's reported size. With no selected rows, the status line shows counts and size totals for the displayed list. Right-clicking a selected table row opens the popup without changing its selection; right-clicking the blank scroll area clears selection first. The popup trigger is checked on both mouse press and release for platform compatibility. This means a bulk operation launched from a blank-area popup starts with an empty selection, while one on a row can act on a retained multi-selection.

## Local and remote filters

[LocalFileFilter](../src/main/java/com/myjavaworld/jftp/LocalFileFilter.java) and the local filter dialog support inclusion/exclusion, regex, modification date range, and hidden-file visibility. [LocalFileFilterDlg](../src/main/java/com/myjavaworld/jftp/LocalFileFilterDlg.java) trims regex/date input, treats empty regex and empty date range as no criterion, uses Java regex with case-sensitive off by default, and parses optional dates with a shared `SimpleDateFormat("yyyy-MM-dd")`. The formatter is not made strict. Validation surfaces regex syntax and date parse messages, focuses the failing control, and keeps the dialog open.

`LocalFileFilter.accept` always accepts directories unless the hidden-directory early check rejects them. For files, regex and date failures are individually inverted in exclusion mode; hidden files excluded by the hidden checkbox are also individually inverted. Thus exclusion mode can include hidden files when `showHiddenFiles` is false. Preserve or deliberately correct this behavior with a regression case: exclusion mode plus hidden file plus failing regex/date. Properties directory totals call `LocalFile.list(filter)`, so a filter affects the displayed recursive count and byte total.

[RemoteFileFilterDlg](../src/main/java/com/myjavaworld/jftp/RemoteFileFilterDlg.java) has the same inclusion/exclusion, regex, date, and optional-input form but no hidden-file option. It creates a `RemoteFileFilter` from the FTP API. Existing filters repopulate the radios, regex pattern/case flag, and optional dates. The dialog shows `yyyy-mm-dd`, but uses the same lenient `SimpleDateFormat` default. Remote listing/property operations pass the active filter into the FTP client listing API.

## File dialogs and properties

Local and remote `Change*DirectoryDlg`, `New*DirectoryDlg`, `New*FileDlg`, and `Rename*FileDlg` validate only that required text is non-empty after `trim()`, then return the original untrimmed control value on approval. They do not check that a path exists, normalize separators, validate a destination, or reject parent/absolute path syntax. Rename dialogs require both from/to values and focus the destination on open when the source is already populated. Treat spaces, Unicode names, slash/backslash paths, and existing-name collisions as caller/API behaviors to preserve or explicitly change; the mutations themselves are handled by action classes outside this source subset.

[LocalFilePropertiesDlg](../src/main/java/com/myjavaworld/jftp/LocalFilePropertiesDlg.java) displays platform filename/type/icon, canonical path with absolute-path fallback, byte size, formatted modified time, and disabled read/write/hidden flags. For a directory it asynchronously traverses descendants through the current filter and displays counts/size; `dirCount` starts at -1 and increments for each directory, while each node's reported size is added. A close flag is polled recursively, but the worker also calls `updateSizeAndContents()` during traversal; GUI-thread confinement should be reviewed before moving or replacing this UI.

[RemoteFilePropertiesDlg](../src/main/java/com/myjavaworld/jftp/RemoteFilePropertiesDlg.java) displays host, remote path, type, size, modified date, link count, owner/group, permission bits, and a recursive checkbox for directories. Its worker saves the current remote working directory, recursively changes directory and lists using the active filter, skips `.` and `..`, then attempts to restore the saved directory on normal traversal return (the restore is not in a `finally` block). Exceptions are printed to stderr; the dialog otherwise continues. The recursive flag is returned separately to the caller. On OK, the name is trimmed and a new `RemoteFile` is created through the parser; if the original attributes have length 10, the nine owner/group/public r/w/x selections are encoded back while preserving character zero. Do not drop symbolic type bits, owner/group fields, recursion, filter effects, or cwd restoration in a replacement.

## Connection and preference dialogs

[ConnectionDlg](../src/main/java/com/myjavaworld/jftp/ConnectionDlg.java) has General, Security, Advanced, and Commands tabs. General requires trimmed non-empty host/user/password and validates the port as an integer in the inclusive 0–65535 range. `setRemoteHost(null)` supplies a fresh host object; when populating, blank user becomes `anonymous` and blank password becomes the global email preference. The saved host/user/password strings are not trimmed after validation. Security choices are no SSL, SSL if available, explicit SSL, and implicit SSL; the implicit SSL port is range-checked only in that mode. The “Do Not Encrypt Data Channel” checkbox maps directly to the data-channel-unencrypted property. The Security panel initially selects no SSL before `setRemoteHost` populates any provided host settings. Advanced preserves FTP client and parser implementation choices, initial local/remote directory text, passive mode, and raw post-login command text.

[FavoritePropertiesDlg](../src/main/java/com/myjavaworld/jftp/FavoritePropertiesDlg.java) reuses these connection/security/advanced/commands fields and adds a required label. It also substitutes anonymous/email defaults for blank user/password during population, validates port and only validates implicit SSL port when that mode is selected, and writes path and command strings without trimming. Its host/IP, credentials, SSL settings, transfer mode, parser, paths, and commands are persisted through Favorite/FavoritesManager. [FavoritesDlg](../src/main/java/com/myjavaworld/jftp/FavoritesDlg.java) sorts favorites in its list, permits edit/connect with one selection, delete with multiple selections, confirms deletion, saves on close/window closing and before connecting, and double-click connects the selected row. It creates a new session if none is current.

[PreferencesDlg](../src/main/java/com/myjavaworld/jftp/PreferencesDlg.java) provides General, Advanced, Proxy, Security, Transfer Modes, Regional Settings, UI, and Software Updates cards. Save validates the first seven panels in order, then calls all save methods (including Software Updates) and writes the global preference object. Restore Defaults repopulates every panel from a new `JFTPPreferences`. Cancel closes without invoking panel save methods, though “Check Now” in `SoftwareUpdatePrefsPanel` starts an updater immediately. [GeneralConnectionPrefsPanel](../src/main/java/com/myjavaworld/jftp/GeneralConnectionPrefsPanel.java) requires email and default local directory after trim, then stores the raw strings. [AdvancedConnectionPrefsPanel](../src/main/java/com/myjavaworld/jftp/AdvancedConnectionPrefsPanel.java) validates buffer size > 0 KB and timeout >= 0 minutes and converts those units when saving. [ProxyPrefsPanel](../src/main/java/com/myjavaworld/jftp/ProxyPrefsPanel.java) validates nonempty host and port 0–65535 only when enabled; blank/non-numeric port is caught, then saved as default 1080, and saving calls `JFTPUtil.updateProxySettings()`.

[SecurityPrefsPanel](../src/main/java/com/myjavaworld/jftp/SecurityPrefsPanel.java) persists the four SSL choices and unencrypted-data preference but does not expose implicit SSL port in global preferences. [CertificatePrefsPanel](../src/main/java/com/myjavaworld/jftp/CertificatePrefsPanel.java) stores client/server certificate store path text; chooser selection returns a canonical path where possible. [LocalePrefsPanel](../src/main/java/com/myjavaworld/jftp/LocalePrefsPanel.java) lists every JVM-available locale, not only the three bundled UI locales, and offers short/medium date/time formats. Its `populateScreen(prefs)` currently selects `Locale.getDefault()` rather than `prefs.getLocale()`; previews are formatted from current date/time. Preserve this observed behavior or explicitly decide to correct it. [LocaleCellRenderer](../src/main/java/com/myjavaworld/jftp/LocaleCellRenderer.java) shows locale display names. [UIPrefsPanel](../src/main/java/com/myjavaworld/jftp/UIPrefsPanel.java) lists installed Swing look-and-feels and falls back to the system look-and-feel when the saved class name is absent. [TransferModesPrefsPanel](../src/main/java/com/myjavaworld/jftp/TransferModesPrefsPanel.java) edits extension-to-ASCII/Binary mappings in a table, stores nonblank extensions in a TreeMap, uppercases extensions on edit, and saves the selected default transfer type. These strings and controls use matching [default `.properties` bundles](../src/main/resources/com/myjavaworld/jftp/) and localized sibling trees.

## Transfer/archive prompts, progress, and errors

[DownloadAsDlg](../src/main/java/com/myjavaworld/jftp/DownloadAsDlg.java) and [UploadAsDlg](../src/main/java/com/myjavaworld/jftp/UploadAsDlg.java) require a non-empty destination name but return the original text. [DownloadAndUnzipDlg](../src/main/java/com/myjavaworld/jftp/DownloadAndUnzipDlg.java) separates download destination (temporary file by default, current local directory, or chosen directory) from extraction destination (current local directory by default or chosen directory); its delete option is true only for temporary downloads. Only chosen directories are required to be nonempty, not validated as existing directories. [ZipAndUploadDlg](../src/main/java/com/myjavaworld/jftp/ZipAndUploadDlg.java) similarly creates a temporary archive by default or writes in the current/chosen directory; for the chosen directory it requires an existing directory. It returns the archive name and whether the temp artifact should be deleted. File names are trimmed when constructing chosen `File` destinations.

These dialog classes only collect options; transfer execution, progress/cancel lifecycle, remote API error mapping, and source/destination collision behavior are in action/session code outside the assigned files. [SessionPanel](../src/main/java/com/myjavaworld/jftp/SessionPanel.java) uses a glass pane to show a busy cursor and stores a title string separately. Property traversal uses the legacy `com.myjavaworld.gui.SwingWorker`; current call sites update some labels while background traversal is running. Do not infer that transfer cancellation is equivalent to closing an option dialog. Fold concrete browser/connection edge cases into the existing four regression suites owned by the application workflow plan; this document does not create an additional standalone suite.

## Behavior risks and regression examples

The following are observed contracts or edges to preserve during a behavior-preserving rewrite. Intentional changes should be identified as such, because otherwise they can hide features or change established handling:

- Local/remote panes keep multi-selection through row popups but clear it on blank-area popups; selection index semantics currently assume no row sorter. Exercise selection after sort, keyboard open/delete, double-click on file vs directory/link, and right-click on selected vs blank space.
- Descending sort moves directories below files; equal local dates may compare equal. Case folding depends on the JVM default locale. Exercise same-name case variants, locale changes, same-size/timestamp ties, and filesystem roots.
- Filters use regexes against basenames, optional `yyyy-MM-dd` date bounds, lenient date parsing, and inclusion/exclusion inversion. Exercise empty criteria, invalid regex, overflow/normalized dates, hidden-file exclusion interaction, and the directory-always-pass rule.
- Connection validates by trimming to check required fields but keeps entered strings intact; paths and commands are passed through verbatim. Test whitespace, Unicode, bracketed IPv6/host strings, port endpoints 0/65535, missing/invalid ports, and implicit SSL's conditional port validation.
- Local properties recurse through filtered contents and remote properties temporarily mutate/restore working directory. Test cancellation/close mid-traversal, list errors, null local listing, symlinks/links, `.`/`..`, permission preservation, and exact remote cwd restoration.
- Temp archive paths can fail to allocate and show an error while the dialog remains approved; caller behavior after a null `File` must be understood. Test temp deletion option and current/chosen path handling. Filename input can contain Unicode and leading/trailing spaces but caller paths may trim only at specific points.

Source descriptions are intentionally scoped to the 44 listed files. FTP protocol command semantics, action classes, transfer worker behavior, `RemoteFileFilter`, `DateFilter`, persistence encryption, and global application initialization remain the responsibility of the broader application workflow review.
